SHIELD visual update

Extract the folder and open index.html. Keep investigate.html beside it.

Navigation: Simulate, Evidence, Explain, shown as flat hyperlinks.
Larger type and metric-card icons improve readability. Export actions include download icons.
The logo, icons, font and truck data are embedded; editable SVG icons and the original GLB and logo are also included. The external model-viewer library requires internet for the 3D truck.

Colours: red/pink for temperatures; green for journey timing; yellow for the warning buffer; blue for thermal response.
The scenario panel grows alongside the results on desktop and stacks above them on narrow screens.
